# Create Artistic Outputs using Neural Art Concepts

## Objective
To generate artistic images using Generative Adversarial Networks (GANs) by exploring the latent space of the generator. Students will investigate how different latent vectors and GAN architectures can produce diverse and creative visual outputs.
## Dataset
Students may use any image dataset suitable for training GAN models.

### Examples:
- CIFAR-10 dataset
- Artwork or painting datasets
- Landscape or object image datasets

### Choose:
- A trained GAN model
- Random latent vectors to generate artistic outputs.

## Lab Tasks

### 1. Data Preparation
- Load the dataset used for GAN training
- Normalize image pixel values (e.g., between −1 and 1)
- Define the latent vector dimension
### 2. Load Trained GAN Model
- Load a trained Generator network
- Freeze the generator weights
- Generate images using random latent vectors

### Students may choose one Basic GAN and one advance GAN architecture from the following:
•	Basic GAN Models:
•	Deep Convolutional GAN (DCGAN)
•	Conditional GAN (cGAN)
•	Advanced GAN Models:
•	StyleGAN
•	CycleGAN
•	BigGAN

### 3. Latent Space Exploration
- Generate images using different latent vectors
- Interpolate between two latent vectors
- Observe how generated images change smoothly

### Tasks:
- Generate 5–10 artistic image samples
- Perform latent vector interpolation

### 4. Generate Artistic Outputs
- Use random latent vectors to create artistic images
- Visualize the generated outputs
- Compare diversity and patterns in generated samples


## Expected Output
### Students should observe:
- New images generated by the GAN generator
- Artistic variations produced from different latent vectors
- Smooth transitions between images during interpolation
- Creative patterns generated without directly copying training images
### Learning Outcomes
After completing this lab, students will understand:
- How GAN models generate creative visual outputs
- The importance of latent space in Generative AI
- Differences between basic and advanced GAN architectures
- How generative models can be used for AI-based artistic content creation
